# Закрывающий тег

Одностраничный сайт, посвящённый историям о разработке и пути создания проекта.

## О проекте

Проект выполнен по макету из Figma.

В работе реализованы:
- адаптивная вёрстка;
- карточки с изображениями и текстом;
- CSS-фильтры для изображений;
- интерактивная кнопка Like;
- анимация SVG-сердца;
- модальное окно;
- SVG-спрайт;
- фавиконы для разных устройств.

## Технологии

Использованы:

- HTML5;
- CSS3;
- JavaScript;
- SVG;
- Flexbox;
- CSS animations;
- CSS transitions.

## Запуск проекта

Для запуска проекта:

1. Скачать или клонировать репозиторий.
2. Открыть проект в редакторе кода.
3. Запустить через Live Server.
